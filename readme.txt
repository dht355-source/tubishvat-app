=== טו בשבט – אפליקציית ניהול ===
Version: 2.4.0
Requires PHP: 8.0 (with ZipArchive, for Excel backups)

מערכת פנימית לניהול לקוחות, מלאי והגדרות מארזים. נפתחת בכתובת /app של האתר.

== התקנה ==
1. בלוח הבקרה: תוספים › הוספת תוסף › העלאת תוסף › בוחרים את tubishvat-app.zip › התקנה › הפעלה.
2. פותחים את https://morvelevona.co.il/app ונכנסים עם חשבון מנהל האתר.
3. אם /app מחזיר "לא נמצא": הגדרות › קישורים קבועים › שמירה (בלי לשנות כלום).

== מה יש בגרסה הזו ==
- לקוחות: רשימה, הצעד הבא, כרטיס לקוח עם פרטי הזמנה, כמה סוגי מארזים בהזמנה אחת (עם תמונות מהאתר), מוצרים נלווים לסימון, תכולת כל מארז, צעדים, טופס אספקה, נקודות אספקה ומייל פתיחה.
- מלאי: נדרש מול קיים למארזים, נספקים ותכולות, ורשימת רכש להעתקה.
- הגדרות: תכולת מארזים (גרם), נספקים לכל מארז, נוסח המייל, כניסה עם Google, Webhook של Tally, גיבויים.
- משתמשים: הזמנה לפי מייל, ארבעה תפקידים, הרשאות נאכפות בשרת.
- גיבוי Excel יומי ב-02:00, 30 אחרונים נשמרים, הורדה ושחזור ממסך ההגדרות.

== נתונים ==
הנתונים נשמרים בטבלאות משלו במסד הנתונים של וורדפרס (wp_tbs_clients, wp_tbs_staff, wp_tbs_kv).
השבתה או מחיקה של התוסף לא מוחקת את הנתונים.

== אבטחה ==
- /app חסום למי שלא מחובר, ולא נכנס למנועי חיפוש או למטמון.
- אנשי צוות שאינם עורכי האתר לא רואים את לוח הבקרה של וורדפרס.
- קבצי הגיבוי נשמרים בתיקייה עם שם אקראי וחסומה לגישה ישירה; הורדה רק דרך המערכת, למנהלים.
